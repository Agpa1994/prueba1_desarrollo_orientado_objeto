Sistema de Gestión de Bicicletas

Descripción

Aplicación desarrollada en Java utilizando Programación Orientada a Objetos (POO) para la gestión de bicicletas eléctricas y bicicletas de montaña.

El sistema permite:

- Registrar bicicletas.
- Buscar bicicletas por código.
- Listar bicicletas registradas.
- Calcular costos de mantención.
- Gestionar garantía extendida para bicicletas eléctricas.
- Aplicar conceptos de herencia, polimorfismo, encapsulamiento, clases abstractas e interfaces.
